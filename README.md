# Layout Adjuster - Настройка макета сайтов под широкие экраны

**Layout Adjuster** - это расширение для браузеров на базе Chromium (Chrome, Яндекс.Браузер, Edge, Brave, Opera, Helium и др.), которое позволяет вручную управлять выравниванием и шириной любых элементов на веб-страницах.

Расширение решает проблему пустых полей по краям экрана и слишком узких контейнеров на широких и ультрашироких мониторах.

##  Возможности

- **Выбор элемента в один клик**: Активируйте режим выбора и кликните по любому элементу на странице (он подсветится красной рамкой).
- **Гибкая настройка выравнивания**: Выровняйте элемент по левому краю, по центру, по правому краю или задайте произвольные отступы (в пикселях) от левого и правого краев.
- **Управление шириной**: Задайте ширину элемента вручную в пикселях или установите `Max Width` (растянуть на всю доступную ширину).
- **Множественные правила на один сайт**: Можно настроить несколько элементов на одной странице (например, центральную колонку, шапку или боковое меню).
- **Умное обновление правил**: Если выбрать уже существующий элемент, расширение автоматически откроет его текущие настройки. При сохранении оно не создаст дубликат, а перезапишет существующее правило.
- **Менеджер правил**: Отдельная вкладка со списком всех сохранённых правил для текущего сайта. Здесь их можно просматривать, удалять или редактировать вручную.
- **Ручное редактирование CSS-селектора**: В режиме редактирования вы можете вручную изменить CSS-селектор (код элемента), что позволяет исправить правило, если сайт изменил классы или ID элементов.
- **Включение/выключение по доменам**: Правила хранятся отдельно для каждого сайта. Вы можете включить или отключить применение правил для конкретного домена.
- **Мгновенное применение**: Сохраненные стили автоматически применяются при каждой загрузке страницы.

## Установка

Так как расширение не опубликовано в Chrome Web Store, установка производится вручную:

1. Скачайте исходный код репозитория (кнопка **Code** -> **Download ZIP**).
2. Распакуйте архив в удобное для вас место.
3. Откройте браузер и перейдите по адресу: `chrome://extensions` (или `edge://extensions`, `helium://extensions` и т.д.).
4. Включите **«Режим разработчика»** (Developer mode) в правом верхнем углу.
5. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) и выберите распакованную папку с файлами.

##  Как пользоваться

1. Нажмите на иконку расширения в панели браузера.
2. Перейдите на вкладку **«Выбор»**.
3. Нажмите кнопку **«Выбрать элемент на странице»**.
4. Наведите курсор на нужный элемент (он подсветится красным) и кликните по нему.
5. В правом верхнем углу страницы появится панель настроек.
6. Выберите выравнивание и ширину, отметьте галочку «Включить правило» и нажмите **«Сохранить»**.
7. Чтобы отредактировать или удалить правило, откройте иконку расширения и перейдите на вкладку **«Правила»**.
